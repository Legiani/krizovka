# Krizovka – uživatelská aplikace

Flutter pro web, iOS a Android. Spuštění, aktuální omezení a ověření popisuje [kořenové README](../../README.md).

```sh
fvm flutter pub get
fvm flutter run -d chrome
```

Vývojový základ zobrazuje Hlášení, Metodiky a Nastavení. Odesílání ani ukládání osobních údajů zatím nejsou zapojené.
